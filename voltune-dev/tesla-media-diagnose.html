Voltune · Tesla Medien-Test

Diagnose für das linke Scrollrad: Erkennt der Tesla-Browser eine Webseite als aktive Medienquelle und kommen die Play/Pause-Befehle dort an?

Nur im geparkten Fahrzeug ausprobieren. Diese Seite erzeugt einen leisen Testton. Wenn Tesla den Browser als Medienquelle übernimmt, wird deine laufende Musik möglicherweise pausiert. Die normale Voltune-App bleibt unangetastet.

1. Medienquelle testen

2. Tesla-Mini-Player prüfen

Wird unten links nach dem Start die Browser-Wiedergabe bzw. eine neue Medienquelle sichtbar?
